LA IDEA EN 30 SEGUNDOS

Una GPU rápida puede ser demasiado valiosa para ocuparla ahora.

Si solo la GPU A puede ejecutar un modelo grande, asignarle todas las peticiones pequeñas podría crear una cola innecesaria. EcoDispatch evalúa también cuánto perjudicaría al próximo trabajo hipotético usar esa GPU.

Eso no significa que siempre deba reservarla. Si el trabajo grande nunca llega, reservar la GPU puede empeorar el resultado.

FUNCIÓN DE DECISIÓN
coste = latencia actual
+ λ × ΔΦ
λ = importancia del futuro
ΔΦ = deterioro estimado de la capacidad futura

El sistema escoge el servidor compatible con la puntuación más baja. En la interfaz web el peso monetario está desactivado.
