BAJO EL CAPÓ / 03

Un laboratorio, no una promesa.

Transparencia primero: estos resultados describen un modelo simplificado, no servidores reales.

01 / EL PROBLEMA

Asignar sin saber el futuro

Las peticiones llegan una a una. El algoritmo conoce el estado actual y una proporción hipotética de modelos grandes, pero no ve las próximas solicitudes.

02 / EL MÉTODO

Penalizar la capacidad perdida

EcoDispatch suma a la latencia inmediata una penalización por deteriorar la capacidad para servir futuras peticiones. λ controla ese equilibrio.

03 / LAS LIMITACIONES

Resultados exploratorios

GPU, rendimiento, costes, llegadas y tiempos son sintéticos. No se modelan batching, fallos, caché KV ni costes cloud reales. No se heredan garantías de k-server.
